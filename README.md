# Overview

This repository documents key data-related decisions made during the analysis for “Sacubitril/valsartan use across transitions between community, hospital, and skilled nursing facility settings" by Corcoran KL, Lo D, Chowdhury T, et al.

To start, see main_documentation.xlsx. This file contains information on:
- authorship
- data sources accessed in this project
- diagnosis codes for conditions relevant to this project
- operationalization of constructs used in the analysis
